Tier 2 — worth it, some cost

- Reminders due today — RemindersService exists, permission already granted
- World clocks — trivial; real value if you work across timezones
- Wi-Fi / VPN status with SSID — CoreWLAN needs Location, which you just granted, so it's now free
- System vitals (CPU / memory / disk) — host_statistics, no permission, but risks turning the notch into iStat Menus
- Screenshot → File Tray — capture a region straight into the shelf; some modes need Screen Recording


Tier 3 — I'd skip, and why

- Focus/DND toggle — no public API. Only reachable via Shortcuts automation, and unreliably
- Bluetooth on/off — no public API; private IOBluetooth calls break between releases
- Media controls — the Media tab already owns this; duplicating splits the mental model
- Clipboard history — Copy Sense already covers the capture case; a full history is a different product with retention and privacy questions you'd have to answer
- Timer/stopwatch — Pomodoro already occupies that groundp
