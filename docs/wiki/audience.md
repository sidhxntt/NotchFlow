# Who NotchFlow Is For

## AI-assisted developers

- Start a local coding task from a selected project folder
- Follow work without keeping the terminal foregrounded
- Respond to supported approvals, questions, and follow-ups
- Jump back to the originating terminal or browser session

For developers, the main value is attention management rather than another code editor. A long-running agent can keep working while the terminal is not frontmost; the notch becomes the place to see a concise status, understand whether intervention is needed, and return to the native tool. The user still chooses the project, engine, prompt, and any follow-up.

## Knowledge workers

- Capture a thought without breaking focus
- Turn a line into a note or reminder
- Ask a short question with a model they control
- Keep active media and useful context within reach

This is for people who collect small pieces of work throughout the day: a sentence from a meeting, a follow-up to remember, an answer needed before returning to the task at hand, or a file that should remain available for a few minutes. The product is useful when the cost of opening a dedicated app exceeds the size of the action.

## macOS productivity users

- Use the notch as a lightweight utility surface
- Keep transient files close without Finder window switching
- Control active media from the display edge
- Use a virtual notch on supported non-notch or external displays

NotchFlow works best for people who prefer a compact, persistent interaction surface over accumulating small windows. It is intentionally not a dashboard: the design favours a resting state, one current item, and a larger view only when the user asks for it.

## Best fit

- Apple-silicon Mac users on macOS 14+
- People comfortable connecting their own provider or already signed-in local CLI
- Users who value local storage and direct service connections

## Less suitable for

- Users who need Windows or Linux support
- Teams needing shared cloud workspaces or remote agent control
- Users looking for a fully autonomous agent that operates the Mac unattended
- Mac App Store-only environments

## A practical setup expectation

NotchFlow itself does not create a cloud account. Users who want hosted AI need to bring the provider access they already trust. Users who want agent execution need an installed, signed-in supported CLI. Notes, reminders, media, files, and many utilities remain useful even without an AI provider.
